## Интерпретация

Выживших мутаций нет, поэтому изменения тестов по результатам анализа
не потребовались. `after` — повторный прогон с теми же операторами и
настройками для проверки воспроизводимости, а не результат усиления тестов.
Исходники и тесты домена и usecase в обоих прогонах одинаковы.
52 обнаруженные мутации не означают отсутствие всех возможных ошибок:
результат ограничен операторами и местами изменений, выбранными Gremlins.

При предварительном запуске со стандартным лимитом времени часть мутаций
домена завершилась по таймауту. Эти результаты не засчитаны как обнаруженные
ошибки. Финальные прогоны ниже используют коэффициент таймаута 100.

## Воспроизведение

Установка фиксированной версии:

```bash
GOBIN="$HOME/.local/bin" go install github.com/go-gremlins/gremlins/cmd/gremlins@v0.6.0
```

В корне отдельной копии проекта выполните команду ниже для каждого пакета
из таблицы, подставляя его путь вместо `internal/domain/trip`:

```bash
"$HOME/.local/bin/gremlins" unleash ./internal/domain/trip \
  --workers 2 \
  --timeout-coefficient 100 \
  --invert-logical \
  --invert-assignments \
  --invert-bitwise \
  --invert-bwassign \
  --invert-loopctrl \
  --remove-self-assignments \
  --output domain-result.json
```

Стандартные операторы Gremlins также остаются включёнными. Файлы тестов
и сгенерированные моки не входят в список мутируемых файлов этих отчётов.
